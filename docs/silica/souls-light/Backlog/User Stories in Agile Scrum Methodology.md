# User Stories in Agile Scrum Methodology

User Stories are a core component of Agile Scrum methodology, defining functional requirements from the end-user perspective (the player). Each User Story adheres to the INVEST principles: Independent, Negotiable, Valuable, Estimable, Small, and Testable.

- **Format**: "As [user], I want [objective], so that [advantage]."
- **Acceptance Criteria**: Associated criteria establish conditions for completion and serve as the basis for testing and validation. Critical requirements (marked in red) are essential for software functionality.

**Examples from the session**:
- Title Screen: As a player, I want to view the screen menu so that I can choose a menu option.
- Merchant Interaction: As players, we want to interact with the Merchant NPC so that we can see and buy available upgrades.
- Stats Purchase: As a player, I want to buy a permanent Max HP increase so that I can survive longer in the next run.

User Stories facilitate structured, user-centric development and prioritization.
