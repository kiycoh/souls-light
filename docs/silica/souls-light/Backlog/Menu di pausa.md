# Menu di pausa

Pause Menu (ID 3): During gameplay, players can open the pause menu to pause the game. When paused:

- Enemies and projectiles stop moving.
- Players can access settings and save progress.
- The game can be exited without losing saved progress.

Pause Menu features include:

- **Start/Continue Run**: Begin a new run or resume the previous one from the main menu.
- **Settings**: Open settings from the main menu.
- **Save System**: Save progress during gameplay via the pause menu.
- **Exit**: End the program from the pause menu or main menu without losing progress.

Audio settings are adjustable via the pause menu, including dynamic music and sound effects.
