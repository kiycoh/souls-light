# Data

Data layer responsibilities in the MVC architecture:

- **Data Layer**: Stores character information and completed levels.

- **Application Layer**: Manages state transitions and game logic, including damage calculation, map changes, and enemy spawning.

- **Presentation Layer**: Renders the map, visualizes movements, and displays status bars (e.g., health, mana).
