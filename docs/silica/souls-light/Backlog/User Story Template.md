# User Story Template

User stories follow the template: **As a [role], I want [feature] so that [benefit]**.

- **Examples**:
  - As a player (Nox), I want to attack in the direction of stick tilt so that I can control combat.
  - As a player (Melee), I want to parry a hit by pressing a button at the right time to negate damage.
  - As a player (Mage/Lux), I want to fire projectiles across the map to damage [[Enemies|enemies]] from a distance.
  - As a player, I want to accept a "double-edged" [[Power-up|power-up]] that doubles inflicted and received damage to bet on dodging ability.
  - As a player, I want to buy permanent stat increases at the start of a run to improve future performance.
  - As a player, I want to interact with the Merchant NPC to view available permanent upgrades.
  - As a Mage/Lux, I want my projectiles to bounce off a second nearby enemy to handle groups.

- **Prioritization**: Stories are marked with priority indicators (e.g., ★★★☆☆ for high priority) and assigned to sprints.
