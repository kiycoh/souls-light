# Dipendenze LibGDX

Elenco delle dipendenze tecniche per il progetto **Souls Light**, basato su **LibGDX** e framework correlati. Le versioni specifiche sono state selezionate per garantire compatibilità e funzionalità avanzate.

- **AI**:
  - `aiVersion=1.8.2` — Libreria per sistemi di intelligenza artificiale.

- **Grafica e Luci**:
  - `box2dlightsVersion=1.5` — Estensioni per illuminazione dinamica basata su Box2D.

- **Controller**:
  - `gdxControllersVersion=2.2.3` — Supporto per controller fisici e input personalizzati.
  - `controllerUtilsVersion=2.2.1` — Utility aggiuntive per la gestione dei controller.

- **UI e Testo**:
  - `lmlVersion=1.10.1.12.1` — Libreria per la gestione di UI basate su markup.
  - `colorfulVersion=0.9.0` — Estensioni per la gestione dei colori.
  - `textratypistVersion=2.2.3` — Motore per effetti tipografici avanzati (es. testo ondeggiante, tremolante).

- **Audio**:
  - `makeSomeNoiseVersion=0.3` — Libreria per la gestione dell’audio dinamico.

- **Utility**:
  - `juniperVersion=0.8.5` — Utility generiche per LibGDX.
  - `digitalVersion=0.9.5` — Estensioni per gestione dati digitali.
  - `jdkgdxdsVersion=1.13.1` — Integrazione tra Java standard e LibGDX.
  - `jdkgdxdsInteropVersion=1.13.1.0` — Interoperabilità avanzata.
  - `funderbyVersion=0.1.2` — Utility per gestione risorse.
  - `regExodusVersion=0.1.19` — Libreria per espressioni regolari.

- **Altre Dipendenze**:
  - `gandVersion=0.3.5` — Estensioni generiche.
  - `cruxVersion=0.1.2` — Framework aggiuntivo.
  - `gdcruxVersion=0.1.1` — Variante di Crux per LibGDX.
  - `tenPatchVersion=5.2.3` — Supporto per patch 9-slice.

- **Note**:
  - Le versioni sono state scelte per garantire stabilità e funzionalità specifiche richieste dal progetto (es. effetti tipografici avanzati tramite TextraTypist).
