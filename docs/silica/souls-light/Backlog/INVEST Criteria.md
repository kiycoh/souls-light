# INVEST Criteria

User Stories in Agile Scrum must adhere to the INVEST criteria to ensure they are well-formed and actionable:

- **Independent**: User Stories should be self-contained and not dependent on other stories to be implemented.
- **Negotiable**: The details are open to discussion and refinement during backlog grooming and sprint planning.
- **Valuable**: Each story must deliver clear value to the end user or stakeholder.
- **Estimable**: The team must be able to estimate the effort required to complete the story.
- **Small**: Stories should be small enough to be completed within a single sprint.
- **Testable**: Each story must have clear acceptance criteria that define when it is considered complete and can be tested.

User Stories follow the format: "As [user], I want [objective], so that [advantage]." Each story is paired with acceptance criteria that establish the conditions for completion and serve as the basis for testing and validation.
