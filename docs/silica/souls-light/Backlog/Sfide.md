# Sfide

Le principali sfide affrontate durante lo sviluppo includono:

- **Scegliere e definire un diagramma UML ottimale** per rappresentare l’architettura del gioco.
- **Definire caratteristiche funzionali** (user stories) e **non funzionali** (requisiti).

**Cambiamenti**:
- **6 novembre 2025**: Scelta del pattern architetturale **Model View Controller (MVC)** per separare la rappresentazione delle informazioni dall’interazione dell’utente.

**Settimana 2 [17/11/2025 - 21/11/2025]**:
- **19 novembre 2025**: Aggiunta degli **story points** alla tabella dei [[Requisiti funzionali|requisiti funzionali]] tramite **Planning Poker**.
- **20 novembre 2025**: Discussione sulle user story con grado infinito e revisione dei documenti, inclusa la suddivisione in epiche e l’aggiunta di ID alle user story.

**[[Problemi e Sfide|Problemi e sfide]]**:
- Aggiornare i criteri di accettazione delle user stories.
- Definire meglio le misure dei requisiti non funzionali.
- Definire meglio gli story points per le user story con grado interrogativo o infinito.
