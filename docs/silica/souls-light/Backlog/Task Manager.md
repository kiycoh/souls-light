# Task Manager

Il **Task Manager** è uno strumento di tracciamento dei compiti utilizzati per suddividere le epiche in user stories granulari e monitorare i progressi durante lo sviluppo del progetto Souls Light.

**Funzionalità principali**
- Visualizzazione di una tabella Google Sheet integrata per il tracciamento dei compiti.
- Segmentazione delle user stories in macroaree tramite chore come [Chore 1] e [Chore 2].
- Inserimento di dati come "bozza" nel documento prima del trasferimento definitivo nel Google Sheet.
- Aggiornamento manuale della tabella tramite icona dedicata in caso di mancata visualizzazione dei dati.

**Cambiamenti e progressi**
- **3 dicembre 2025**: Aggiunte ulteriori user stories, creazione di entry per test, sprite aggiuntive e diagrammi UML.
- **Settimana 5 [08/12/2025 - 12/12/2025]**: Obiettivi e progressi registrati per il tracciamento delle attività.

**[[Sfide]]**
- Segmentare le user stories in macroaree per una gestione più efficiente.
- Mantenere la coerenza tra i dati inseriti nel documento e quelli nel Google Sheet.
