# Cooldown

Cooldown mechanics in Soul’s Light:

- **Primary Attack**: Enters cooldown after use. If no enemy is in range, attack is performed in the character’s facing direction.

- **Parry Mechanic**:
  - Window: 0.2s activation window.
  - Success: If stick direction matches incoming attack direction, damage is negated (0 damage).
  - Failure: Full damage + parry cooldown activated.

- **Special Ability**: Not activable if in cooldown. Visual cooldown timer displayed on icon.

- **Weapon Switch**: Immediate replacement upon picking up a new weapon via interact key.
